# VotingAppClient

Android-клиент приложения для голосований.

## Что есть

- экраны входа и регистрации;
- лента активных голосований;
- поиск с историей до 10 элементов;
- создание голосования;
- экран голосования и результатов;
- сохранение темы и истории поиска через DataStore;
- светлая и тёмная тема.

## Сервер

В эмуляторе Android клиент обращается к серверу по адресу:

```text
http://10.0.2.2:8080/
```

Перед запуском клиента нужно поднять сервер из репозитория `VotingAppServer`.

## Сборка

```bash
./gradlew build
```

На Windows:

```bat
gradlew.bat build
```

## Запуск

Открыть проект в Android Studio, выбрать модуль `app` и запустить на эмуляторе или устройстве.
